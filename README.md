# 大肥鱼的自拍 · astrbot_plugin_selfie

> 聊天聊到有画面感的时候，她自己决定拍一张。

AstrBot 插件。日常对话里让她自己判断「这轮值不值得拍张照」，值得就自己写一条完整的英文提示词，
交给本地 ComfyUI + 她的专属 LoRA 出图，然后把图发出来。

不是关键词触发，也不是定时发图——**判断权在她手上**。

---

## 它做了什么

| 能力 | 说明 |
|---|---|
| **自主判断** | 每攒够 N 条消息，她读一遍最近聊天，判断有没有值得拍的画面（在吃什么、去了哪、什么天气、什么心情） |
| **自己写提示词** | 判断成立后由她自己写完整的英文生图提示词，含景别、姿势、表情、场景、光线 |
| **本地出图** | 调用本地 ComfyUI 桥接（OpenAI 兼容接口），用她的 LoRA 出图，一张约 15-30 秒 |
| **只说大概** | 发图时只配一句「她在干嘛」，不暴露提示词和参数 |
| **不发表情包** | 同一轮已经发了图，就把表情包去掉，免得一图一包刷屏 |
| **空间联动** | 主人发说说点单时，可以让她顺手画一张配图，画面按说说方向来 |
| **档位可调** | LoRA 用第几档、权重多少，都在配置里调，不重启生效 |

---

## 装之前要准备什么

```
1. 本地能出图           ComfyUI 装在跑，端口 8188
2. 一个桥接服务         把 ComfyUI 包成 OpenAI 兼容接口，默认 8190
3. 她的 LoRA            训练好的 safetensors，放进 ComfyUI 的 models/loras
4. 桥接支持按档位取权重  请求里带 lora_step / lora_strength 即可
```

桥接不是本插件的一部分。最简的验证方式：

```bash
curl -X POST http://127.0.0.1:8190/v1/images/generations \
  -H "Content-Type: application/json" \
  -d '{"prompt":"dafeiyu, 1girl, solo, selfie","size":"832x1152","lora_step":12,"lora_strength":0.7}'
```

能返回 `b64_json` 就说明链路通了。

## 安装

1. 把整个文件夹丢进 `AstrBot/data/plugins/`，重启 AstrBot。
2. 打开面板 → 插件 → **大肥鱼的自拍** → 配置。
3. **必填①：主人的 QQ**。留空会退回 AstrBot 管理员判定，而管理员默认是 `astrbot` 这个用户名，永远匹配不上 QQ 号。
4. ②机器人的 QQ 留空即可（自动用协议端登录号）。
5. 想让她在群里也发，把 ③群聊生图 打开；默认是关的。

---

## 指令

| 指令 | 作用 |
|---|---|
| `/自拍` | 让她现在拍一张，不受冷却限制 |
| `/自拍状态` | 看档位、权重、群聊开关、冷却、累计张数、上次在干嘛 |
| `/自拍帮助` | 列出全部指令 |

平时不需要指令，她自己会判断。

## 配置项

| 项 | 默认 | 说明 |
|---|---|---|
| `enabled` | 开 | 总开关 |
| `owner_ids` | 空 | **必填**，主人 QQ，多个用英文逗号 |
| `bot_ids` | 空 | 机器人 QQ，留空自动识别 |
| `group_enabled` | 关 | 群里允不允许生成图片 |
| `lora_step` | 12 | 用第几档 LoRA，12 是实测最像又不僵的一档 |
| `lora_strength` | 0.7 | 权重。0.7 自然、像生活照；0.85~1.0 身份更稳但构图端着 |
| `bridge_url` | `http://127.0.0.1:8190` | 生图接口 |
| `size` | `832x1152` | 出图尺寸，竖图最像手机自拍 |
| `steps` | 28 | 采样步数，20~32 |
| `cfg` | 5.5 | Illustrious 系底模建议 5~6，高了发僵 |
| `selfie_check_every` | 10 | 每多少条消息判断一次 |
| `cooldown_minutes` | 30 | 两次生成的最小间隔 |
| `send_probability` | 0.8 | 判断成立后真的发的概率 |
| `suppress_sticker` | 开 | 生图后不发表情包 |
| `qzone_attach` | 开 | 允许空间说说配图 |
| `notify_owner` | 关 | 生成后私聊通知主人 |
| `max_keep_images` | 200 | 本地最多留多少张 |

## 和空间插件怎么联动

装了 `astrbot_plugin_qzone_mood` 的话：

```
/空间 今天去了海边        → 先说文案，再让她画一张海边的照片当配图
/空间 今天去了海边 不带图  → 只发文字和表情包，不画
/空间 今天去了海边 带图    → 强制画一张
```

这条只在**主人点单**时生效；自动触发（难过、断粮、自由发帖）不会画图，省时间也省显卡。

## 版本历史

### 1.0.0
首个版本。

- 自主判断：每 N 条消息读一遍上下文，自己决定要不要拍
- 自写提示词：她自己写完整英文 tag，含景别 / 姿势 / 表情 / 场景 / 光线
- 本地出图：走 ComfyUI 桥接，支持按档位（默认 12）和权重（默认 0.7）取 LoRA
- 表情包抑制：同一轮已发图就去掉表情包
- 空间联动：主人点单可配图，文案里「带图 / 不带图」可强制开关
- 指令：`/自拍` `/自拍状态` `/自拍帮助`
